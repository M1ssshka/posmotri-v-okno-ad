# Посмотри в окно

«Посмотри в окно» — учебный веб-проект, в котором можно посмотреть видео из разных городов и выбрать, каким будет вид из окна в зависимости от времени суток.

## Возможности

- Просмотр видео в основном плеере.
- Поиск видео по названию города.
- Фильтрация по времени суток: утро, день и ночь.
- Переключение видео при выборе карточки в списке.
- Загрузка дополнительных карточек по кнопке «Показать ещё».
- Отображение анимации загрузки и сообщения, если видео не найдены или произошла ошибка.

## Технологии

- **HTML5** — структура страницы и шаблоны динамических элементов (`<template>`).
- **CSS3** — Flexbox, оформление карточек, кастомные чекбоксы, состояния интерактивных элементов и прокрутка списка.
- **JavaScript** — работа с формой, запросы к API, вывод карточек и переключение видео.

## Как запустить

1. Скачайте проект и распакуйте архив.
2. Откройте папку `posmotri-v-okno-ad` в редакторе кода.
3. Запустите `index.html` в браузере. Для локальной разработки удобно использовать **Live Server**.
4. Дождитесь загрузки видеороликов, затем выберите карточку или задайте параметры поиска.

**Важно:** для работы приложения требуется подключение к интернету: список видео и медиафайлы загружаются с внешнего API `https://v-content.practicum-team.ru`.

## Особенности вёрстки

В рамках проектной работы выполнено оформление готового приложения по макету: настроена двухколоночная компоновка, размеры видео и карточек, прокручиваемый список, форма поиска, пользовательские чекбоксы и состояния `hover`, `active`, `focus-visible`. Макет рассчитан на экран шириной **от 1200 px**. Мобильная адаптация в рамках этого задания не предусмотрена.
